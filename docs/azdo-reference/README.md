# Azure DevOps process reference

Drop your **work process screenshots** here (PNG, JPG, or WEBP). A batch of ~100 is fine; they are read in groups to extract patterns—not transcribed one-by-one.

## What happens next

1. Agent reviews images in batches (hierarchy, sample feature, acceptance criteria, linking).
2. Patterns are written to [`work-item-template.md`](../work-item-template.md).
3. [FEATURES.md](../../FEATURES.md) and files in [`features/`](../../features/) are aligned to that template (headings, status values, AC format).

## Until screenshots exist

Features use the **default template** in `work-item-template.md` (User stories → Requirements → Acceptance criteria → Decisions).

## Tips

- Include at least one **complete feature** screenshot set (title, description, AC, links).
- Name files in order if helpful: `01-epic.png`, `02-feature-empty.png`, etc.
